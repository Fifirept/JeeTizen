🎬 JeeTizen - Installation Guide

📋 Prérequis

  • Jeedom 4.2.0+
  • Samsung Tizen TV 2016+
  • PHP 7.4+
  • Accès direct à la TV sur réseau

🔧 Installation

  1. Télécharger le plugin
  2. Exécuter: composer install
  3. Redémarrer Jeedom
  4. Créer un nouvel équipement
  5. Configurer l'IP et le port
  6. Sauvegarder (token généré automatiquement)
✓ Succès : Status "Online" indique la connexion établie.
