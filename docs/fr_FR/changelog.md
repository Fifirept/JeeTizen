# Changelog JeeTizen

## 1.0 (2026-03-26)
- Réécriture complète basée sur le template officiel Jeedom
- Intégration des librairies Samsung de TvDomSamsung (TvConnector, TvParametres)
- Support modèles : Tizen Standard, Modèle K, Modèle J, Legacy
- Wake On LAN (direct + broadcast) via phpwol
- Gestion automatique du token d'authentification
- Commandes : Marche/Arrêt, Extinction, Mute, Volume, Chaînes, Source, Zap, Touche, Auth, Etat
- Latences configurables (touches normales et numériques)
- Vérification d'état par cron (ping port WebSocket)
- Librairies bundlées (aucune dépendance à installer)
